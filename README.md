# altauto showcase

## AI의 제안을, 추적할 수 있는 연구 과정으로

**작업과 출처, 실행 결과를 연결하는 연구 관리 도구 altauto의 합성 데모입니다.**

[브라우저에서 데모 보기](https://altakori.github.io/altauto-showcase/)

에이전트가 답을 내놓는 것만으로 연구가 완성되지는 않습니다. 어떤 자료를 읽었는지, 인용이 원문과 맞는지, 조건이 바뀐 작업을 그대로 실행하지는 않았는지 확인할 수 있어야 합니다. altauto는 이 과정을 명시적인 작업과 실행 기록으로 남깁니다.

이 저장소는 **실제 CLI로 실행한 합성 데모의 결과와 설명 화면만** 제공합니다. 개발 저장소의 소스 코드, 내부 운영 문서와 Git 이력은 포함하지 않습니다. 누구나 화면과 공개 기록을 읽고 서로 대조할 수 있지만, 이 파일만으로 altauto 엔진을 실행하거나 전체 실험을 재현할 수는 없습니다.

### 먼저 살펴보기

1. 웹 데모를 열거나, 저장소를 내려받아 `index.html`을 브라우저에서 엽니다.
2. 4개 클러스터에 나뉜 18개 작업 노드에서 흐름을 따라갑니다.
3. 노드를 누르면 해당 명령과 종료 코드로 이동합니다.
4. `summary.json`, `transcript.json`, `report.md`에서 실제 결과를 대조합니다.

별도 설치나 API 키는 필요하지 않습니다. 페이지 자체에는 JavaScript, 외부 폰트, 분석 도구나 모델 호출이 없습니다. 파일을 내려받으면 오프라인에서도 볼 수 있습니다.

## 움직이는 화면과 실제 실행 기록

**움직임은 완료된 기록을 순서대로 보여 주는 UI 시뮬레이션입니다.** 새 연구나 계산을 실행하는 화면이 아닙니다.

- **출처·인용:** 작업 선택, 원문 등록, 인용 기록과 읽기 완료
- **로컬 계산:** 합성 숫자 배열의 제한된 계산
- **안전장치:** 잘못된 인용, 중복 실행, 조건 변경 뒤의 오래된 작업 거부
- **상태·보고:** 상태 확인, 별도 프로세스에서 완료 결과 다시 읽기, 보고서 생성

중앙에는 현재 재생 중인 작업 이름, 소속 클러스터, 대상 파일 또는 작업 ID가 표시됩니다. 노드당 3초, 전체 54초로 반복하지만 이는 화면 연출 시간이며 실제 실행 시간이 아닙니다. 연결선은 분류와 화면 배치를 나타내며 인과관계의 증거가 아닙니다.

애니메이션은 기본으로 재생되며 일시정지할 수 있습니다. 기기의 ‘동작 줄이기’ 설정이 켜져 있어도 기본 재생합니다. 이 경우 ‘동작 줄이기 설정에서도 재생’ 체크를 해제하면 정지 화면으로 바뀝니다. 노드 설명은 마우스와 키보드 초점으로 확인할 수 있고, 모바일에서는 클러스터별 세로 배열로 표시됩니다.

## 실제로 확인한 결과

합성 입력으로 **CLI 호출 18개, 검증 항목 10개**를 실행했습니다. 최종 기록에는 작업 3개, 인용을 포함한 finding 1개, 계산 run 1개가 남습니다.

| 확인 대상 | 기대한 결과 |
| --- | --- |
| 작업 선택 | 수락한 작업 ID를 명시적으로 선택 |
| 원문과 인용 | 원문 해시·revision·일치하는 인용문을 연결 |
| 잘못된 인용 | 원문에 없는 문장을 거부하고 실행 원장을 변경하지 않음 |
| 제한된 계산 | 합성 배열의 평균 2와 3, 차이 1을 기록 |
| 중복 실행 | 같은 작업의 재실행을 거부하고 추가 run을 만들지 않음 |
| 조건 변경 | 이전 조건의 실행과 판단을 거부하고 기존 결과를 유지 |
| 상태 재개 | 별도 CLI 프로세스에서 완료된 결과를 다시 읽음 |
| 보고서 | 출처·인용·계산 결과와 해석의 한계를 함께 기록 |

18개 호출 중 4개는 의도적으로 거부되는 경로입니다. 이 호출의 기대 종료 코드는 2이며 정상 호출의 기대 종료 코드는 0입니다. 단순히 오류가 발생했다는 이유로 통과시키지 않고, 오류 내용과 원장 불변 여부를 함께 확인했습니다. 세부 검증 10개는 `summary.json`의 `checks`에 있습니다.

## 공개 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 실행 기록에서 생성한 독립형 HTML/CSS 화면 |
| `summary.json` | 10개 검증과 18개 명령의 기대·실제 종료 코드 |
| `transcript.json` | 경로 정보를 정제한 실제 명령 호출과 출력 |
| `report.md` | 출처·인용·계산 결과와 해석 범위 |
| `manifest.json` | 위 파일과 README의 바이트 단위 SHA-256 |
| `README.md` | 데모의 사용법, 공개 범위와 한계 |

공개 저장소에는 이 자료 6개와 빈 `.nojekyll` 배포 표식만 둡니다. `.nojekyll`은 GitHub Pages가 Markdown을 다른 파일로 변환하지 않고 원래 경로와 바이트로 제공하도록 합니다.

### 기록을 읽을 때 주의할 점

- `report.md`의 `Local copy: source.md`와 `local-copy-exists`는 데모 실행 당시 확인한 원문 사본을 뜻합니다. `source.md` 자체는 이 공개 패키지에 없으므로, 공개 파일만으로 원문 바이트와 인용을 다시 대조할 수는 없습니다.
- `read-note`의 작업 설명에는 두 실패 유형을 추출하라는 요구가 있지만, 이 데모는 인용 1개의 연결만 검증합니다. `completed`는 명시적인 완료 처리가 기록됐다는 뜻이며, 작업 설명의 모든 요구나 문헌 검토의 충분성을 자동 판정했다는 뜻은 아닙니다.
- 보고서 하단의 `llm-*` 문장은 도구의 일반 안내입니다. 이 데모의 18개 호출에는 해당 명령이 없으며, 모델 어댑터의 품질이나 안전성은 검증하지 않았습니다.
- 조건 변경 뒤 실행 거부의 오류는 `task is not pending`입니다. 오래된 작업이라는 해석은 조건 변경과 `needs_review` 상태를 함께 보고 판단하며, 그 오류 문구 하나만으로 중복 실행과 구별하지 않습니다. 오래된 판단 거부에는 별도의 stale 오류가 기록돼 있습니다.

### 파일 무결성 확인

Python 3가 있다면 아래 코드를 `verify_preview.py`로 저장하고, 내려받은 파일이 있는 폴더에서 `python -I verify_preview.py`로 실행하세요. `manifest.json`의 형식과 링크 여부, 명시된 5개 파일의 링크 여부·해시를 검사합니다. **폴더의 추가 파일이나 파일 내용의 안전성은 검사하지 않습니다.**

Git 클론 시 줄바꿈 변환을 켰다면 원본 바이트와 달라질 수 있으므로, 파일 변환 없이 받은 ZIP을 기준으로 확인하세요.

```python
import hashlib
import json
from pathlib import Path

root = Path.cwd()
names = {"README.md", "index.html", "report.md", "summary.json", "transcript.json"}
manifest_path = root / "manifest.json"
passed = False

try:
    if manifest_path.is_file() and not manifest_path.is_symlink():
        manifest = json.loads(manifest_path.read_text(encoding="utf-8"))
        valid = (
            isinstance(manifest, dict)
            and manifest.get("schema") == "altauto-preview-manifest-v1"
            and isinstance(manifest.get("files"), dict)
            and set(manifest["files"]) == names
        )
        if valid:
            passed = all(
                (root / name).is_file()
                and not (root / name).is_symlink()
                and hashlib.sha256((root / name).read_bytes()).hexdigest()
                == manifest["files"][name]
                for name in names
            )
except (OSError, ValueError, TypeError):
    passed = False

print("PASS" if passed else "FAIL")
raise SystemExit(0 if passed else 1)
```

성공하면 `PASS`와 종료 코드 0, 누락·불일치·잘못된 형식이면 `FAIL`과 종료 코드 1을 반환합니다.

해시 일치는 파일이 기록된 내용과 같다는 뜻입니다. 저장소와 manifest를 함께 바꿀 수 있는 공격자를 검출하는 전자서명이나 과학적 검증을 대신하지 않습니다.

## 이 데모가 주장하지 않는 것

- 인용문 일치는 보관한 원문과의 일치일 뿐, 출처의 진실성이나 결론의 타당성을 증명하지 않습니다.
- 합성 배열의 평균 차이는 연구 성능 향상, 통계적 유의성 또는 일반화의 증거가 아닙니다.
- 상태 재개는 완료 결과의 보존을 확인하며, 실행 중이거나 중단된 원격 작업의 복구를 시연하지 않습니다.
- 모델 품질, GPU 실행, 실제 운영 환경의 복구 능력, 속도·비용 절감은 평가하지 않았습니다.
- 공개된 기록은 검토할 수 있지만, 비공개 엔진과 입력 파일 전체를 제공하지 않으므로 완전한 독립 재실행을 보장하지 않습니다.

실제 연구 자료, 개인정보, 기관 내부 문서와 개발 이력은 이 패키지에 포함하지 않습니다. 별도의 오픈소스 라이선스는 부여하지 않으며, 이 데모 공개가 비공개 엔진의 사용·배포 권한을 의미하지는 않습니다.
